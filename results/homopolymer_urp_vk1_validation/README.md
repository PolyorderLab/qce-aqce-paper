# Homopolymer URP/VK1 validation figures

These supporting figures document the URP/VK1 saddle-field approximations:

- [urp_vk1_error_map.svg](urp_vk1_error_map.svg) shows the relative closure
  error over prescribed-density amplitude and wavenumber.
- [urp_vk1_saddle_profile.svg](urp_vk1_saddle_profile.svg) shows the auxiliary
  saddle potential generated by prescribed density II; the inset is the imposed
  density. These are auxiliary-potential curves, not independently relaxed
  density profiles.

The [source/](source/) directory contains the two vector PDFs, `.dat` and `.mat`
numerical inputs, the density-II run input, and plotting scripts. To reproduce
the figures directly from the PDFs, use the command below. The scripts inside
`source/` require additional local modules.

From the repository root, redraw the stored PDFs with the shared publication
renderer (Poppler's `pdftocairo` is required):

```bash
uv run python -c 'from scripts.render_macromolecules_figures import render_homopolymer; render_homopolymer()'
```

See [REPRODUCING.md](../../REPRODUCING.md) to generate all manuscript and SI
figures together.
